# 🛡️ تطبيق رصد | Rasd Mobile Application

المنصة الميدانية لإدارة العمليات والمهام الميدانية للفرق المصرح لها بالمملكة العربية السعودية 🇸🇦.

---

### 📲 تحميل التطبيق الميداني (Official Releases)

* لتحميل أحدث إصدار رسمي من التطبيق، يرجى التوجه إلى قسم **[Releases](../../releases)**.
* قم بتحميل ملف **`rasd-app.apk`** وتثبيته مباشرة على جهاز الأندرويد الخاص بك.
* التطبيق مخصص لمنسوبي المنظومة المصرح لهم فقط ويتطلب تسجيل دخول رسمي لبدء العمليات.
